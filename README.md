# Gŏdka – Schlesisch/Polnisch lernen

Kleine Lern-App fürs iPhone: Satz des Tages, Lernpfad mit Lektionen, Wörterbuch mit Verb-Konjugation (ich, du, er/sie/es …), Aussprache in deutscher Schreibweise („Sprich: JES-tem GWOD-na“), Audio und Familien-Aufnahmen.

**Benutzen:** Die GitHub-Pages-Adresse in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

- Fortschritt und Aufnahmen bleiben nur auf dem jeweiligen Gerät gespeichert.
- Schlesische Wörter sind mit „Familien-Check“ markiert und sollten von Muttersprachlern bestätigt werden.
- Die eingebauten Audiodateien kommen aus einer Computerstimme (espeak-ng). Besser klingen die polnische iPhone-Stimme oder eigene Aufnahmen.
